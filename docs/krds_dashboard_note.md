# KRDS 화면 위계 참고 노트 (2026. 11. 4.)

캡처: `artifacts/krds_ref/` (01_배지, 02_표, 03_디스클로저, 04_탭, 05_서비스패턴, 06_온통청년)

## 본 화면과 관찰

| 화면 | 한눈에 볼 한 가지 | 요약, 목록, 상세 연결 | 상태 표시 |
|---|---|---|---|
| KRDS 배지 컴포넌트 쪽 | 쪽 제목 "배지 Badge" 한 줄 | 왼쪽 사이드 메뉴(선택 항목은 회색 면과 굵은 글자), 가운데 본문, 오른쪽 "이 페이지의 구성" 목차가 같은 위치를 가리킴 | 배지는 상태 2개 이상일 때만, 한 요소에 하나, 주조색 바탕 금지, 누를 수 없음 |
| KRDS 표 컴포넌트 쪽 | 표 머리와 행 | 표 위 제목과 건수, 행 선택은 같은 행 강조 | 글자색과 아이콘 |
| KRDS 디스클로저 쪽 | 접힌 제목 | 부가 정보는 한 구역에 하나만 접어 둠 | 펼침 화살표 |
| KRDS 탭 쪽 | 개요, 접근성, 코드 탭 | 같은 주제의 다른 깊이를 탭으로 나눔 | 선택 탭 굵게와 밑줄 |
| 온통청년(KRDS 적용 사례) | 첫 화면 큰 배너 하나 | 주 영역과 오른쪽 개인 패널 두 단 | 단추 색으로 주 행동 하나 |

## 적용 원칙

- 한 화면 한 주제와 주 행동 하나(현황판: 판정 카드, 판정 카드: 현장 측량 구간 CSV, 사업지 분석: 분석 실행)
- 첫 화면 주역은 지도 한 장. 오른쪽에 큰 숫자 3개(기준 초과, 구조물 의심, 판정 보류)와 선택 가로선 상세, 아래 가로선 목록
- 지도 가로선을 누르면 상세와 목록 행이 함께 바뀜. 목록 행을 누르면 지도 가로선이 굵어짐
- 같은 크기 숫자 카드 4개, 모든 영역 흰 카드 금지(KRDS 키트 규칙). 큰 숫자는 구분선으로 나눔
- 판정 표시는 아이콘과 글자색(전진 파랑, 후퇴 빨강, 판정 보류 회색, 구조물 의심 기울임)
- 전문 표(오차 유형별 점수 변동, 해빈폭별 점수)는 판정 카드의 별표 10 점수와 상세 탭으로 내림
- 글자 위계: 쪽 제목 24, 구역 제목 17, 본문 15, 보조 13. 큰 숫자 36과 32
