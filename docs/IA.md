# 해안선 성적표 화면 구조

## 셸

- 1024 폭 이상: 왼쪽 메뉴 고정, 위쪽에 사업지 선택줄
- 1024 폭 미만: 위쪽 줄의 메뉴 단추로 서랍 메뉴를 엶. Esc 키와 바깥 누름으로 닫음
- 사업지 선택줄은 판정 카드, 해안선 지도, 전후 영상 비교 화면에서만 보임. 단추 앞 점은 자료 상태(청록 준비, 회색 불러오는 중 또는 없음, 빨강 오류)
- 주소 해시가 화면과 사업지를 기억함. 예: `#/card?site=banam`

## 메뉴와 화면

| 메뉴 | 주소 | 내용 | 다음 이동 |
|---|---|---|---|
| 지구본(첫 진입) | #/globe | 위성 궤도 5기와 사업지 핀, 촬영 일정 샘플 | 핀이나 목록을 누르면 판정 카드 |
| 사업지 목록 | #/sites | 사업지 5곳 카드, 판정 가능과 보류 비율 | 카드를 누르면 판정 카드 |
| 판정 카드 | #/card | 대장에 옮겨 적는 한 장. 9장 설계 | 사업지 선택줄로 다른 사업지 |
| 해안선 지도와 시간 축 | #/map | 장면별 해안선, 가로선 판정 색, 장면별 이동 거리 | 사업지 선택줄 |
| 전후 영상 비교 | #/compare | 이전과 이후 위성 영상 비교 손잡이 | 사업지 선택줄 |
| 폭풍 뒤 점검 목록 | #/storm | 판정 가능하고 변화가 큰 가로선 순서, 점검 표시와 메모 | 지도에서 보기 단추로 해당 사업지 지도 |
| 근거와 출처 | #/sources | 출처 표기, 이용 조건, 한계, 정의, 촬영 간격 | 없음 |

## 자료 흐름

1. 시작 때 `public/config/sites.json`을 읽고 사업지 5곳 자료를 동시에 읽음
2. 사업지 자료는 개발 서버 주소 `/ext/poc2/<사업지>/`(erosion_poc2 폴더)에서 읽음
3. 민감도와 규칙 파일 `/ext/poc2/sensitivity_and_rules.json`은 선택 자료. 없으면 판정 카드의 등급 변동 폭 칸이 "계산 중"
4. 점검 표시와 메모는 브라우저 저장소(localStorage)에만 둠
