# 해안선 성적표 부품과 상태

모든 공유 부품은 `src/ui/index.jsx` 한 파일에 있다. 셸은 `src/shell/`, 시간 축과 접힘 부품은 미리에서 가져온 `src/miri/`를 쓴다.

## 부품 목록

| 부품 | 역할 | 상태 |
|---|---|---|
| AppShell | 왼쪽 메뉴, 서랍 메뉴, 사업지 선택줄, 본문 바로가기 | 메뉴 선택, 서랍 열림, 사업지 상태 점 |
| PageHeader | 화면 제목, 설명, 표시 칩 | 시험값 칩, 조위 칩 |
| Card | 카드 면, 제목, 오른쪽 행동 | 없음 |
| Chip | 짧은 표시 | 전진, 후퇴, 보류, 모래(시험값과 샘플), 주색, 중립 |
| TestBadge, TestNotice | 시험값 표시 칩과 안내 줄 | 모든 판정 화면 |
| TideBadge | 조위 보정 또는 조위 미보정 | 가로선 tide_corrected 값으로 정함 |
| Button | 주요, 부드러움, 투명 | 누름, 비활성, 초점 |
| Stat | 개수와 비율 칸 | 전진, 후퇴, 보류, 주색 글자 |
| ChangeBars | 가로선별 전후 변화 막대(왼쪽 후퇴, 오른쪽 전진) | 값 없음, 보류 |
| DefList | 항목 이름과 값 | 좁은 폭에서 위아래 배치 |
| StateBlock | 상태 칸 | 불러오는 중, 자료 없음, 오류, 판정 보류 |
| SiteState | 사업지 자료 상태를 StateBlock으로 바꿈 | loading, empty, error |
| TimeAxis(미리) | 장면 단위 시간 축, 재생 | 움직임 줄이기 설정이면 한 장면씩 |

## 화면별 상태 설계

| 화면 | 불러오는 중 | 자료 없음 | 오류 | 판정 보류 |
|---|---|---|---|---|
| 설정 전체 | 상태 칸 | 사업지 0곳 안내 | 상태 칸과 다시 읽기 단추 | 해당 없음 |
| 사업지 목록 | 카드 안 문구 | 분석 자료 없음 | 자료를 읽지 못했습니다 | 보류 개수와 비율 |
| 판정 카드 | 상태 칸 | 상태 칸 | 상태 칸 | 보류 가로선 번호와 할 일 한 줄 "해당 가로선은 현장 측량으로 확인합니다." |
| 해안선 지도 | 상태 칸 | 상태 칸 | 바탕 지도 오류 칸 | 보류 가로선 색, 구름으로 값 없는 가로선 안내 |
| 전후 영상 비교 | 상태 칸 | 비교 영상 없음 | 영상을 읽지 못했습니다 | 해당 없음 |
| 폭풍 뒤 점검 목록 | 상태 칸 | 판정 가능 가로선 없음 | 저장소 저장 실패 칸 | 보류 개수와 현장 측량 안내 |
| 근거와 출처 | 사업지마다 불러오는 중 | 분석 자료 없음 | 읽기 오류 | 해당 없음 |

## 문구 규칙

- 화면 문구는 명사형 라벨과 합니다체 문장
- 제목에 질문형과 "~것"을 쓰지 않음
- 책임 원칙 한 줄: "위성 판정은 참고 자료이고 최종 판단은 관리주체의 현장 점검이 정합니다."
- 대장 옮김 문구는 판정 가능 가로선만 넣음(`src/lib/ledger.js`)

## 접근성

- 본문 바로가기 링크, 모든 단추와 링크에 3px 청록 초점 고리
- 서랍 메뉴는 열릴 때 닫기 단추로 초점 이동, Esc 키로 닫고 메뉴 단추로 초점 복귀
- 상태 칸은 role=status, 오류는 role=alert. 복사 결과는 화면 읽기 프로그램에 알림
- 영상 비교 손잡이는 range 입력이라 방향키로 움직임
- 대비는 DESIGN.md 대비 계산 결과 참고
